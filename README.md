# Apsolute

Next.js (App Router) website for Apsolute.

## Scripts

- `npm run dev` – start the dev server at http://localhost:3000
- `npm run build` – create a production build
- `npm start` – serve the production build

Routes live in `src/app/`, shared components in `src/components/`, styles in `src/css/`, and static assets in `public/`.
